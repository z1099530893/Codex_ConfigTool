# 变更摘要

## 1.2.0

- 将产品定位统一为 Codex 配置管理与切换工具
- 新增固定窗口、左侧导航和当前配置只读页面
- 新增配置库搜索、排序、切换、完整编辑、重命名、删除和批量删除
- 新增全选、Ctrl+A、鼠标左键拖选和双击空白区域切换
- 配置永久保留，不设数量上限，不自动删除或更新时间
- 保存相同核心配置时复用已有配置，避免重复目录
- 新增官方登录页面和一次性居中新手引导
- 增加 Windows 单实例限制和正常退出后的互斥量释放
- 统一软件图标、眼睛图标、扁平按钮、列表边框和自绘滚动条
- 瞬时消息改为无背景纯文字，眼睛按钮移除悬停提示
- 最小化和关闭图标改为以按钮几何中心绘制，修正字体基线导致的视觉偏移
- README、HANDOFF、测试和 PyInstaller 打包资源同步更新
- 统一当前配置页和已保存配置页的标题、控件高度与底部瞬时提示区域
- 启动新手引导改为“是/否/不再弹出”，明确禁用前每次启动继续询问
- 标题栏按钮改用独立清晰图标，任务栏与弹窗分别使用对应图标资源
- Windows 使用原生任务栏缩放动画，并通过非客户区处理保留单一自绘标题栏
- 侧栏和弹窗分别原尺寸加载 105/210 像素赞赏码
- 多选右键仅提供批量删除；删除匹配项后保留当前配置文件并显示为未保存配置
- 配置与设置改用同目录原子替换，双文件保存失败时自动回滚
- 配置签名和列表搜索增加自动失效的 512 项 LRU 缓存
- 增加写入故障注入、事务回滚和缓存失效测试
- EXE 嵌入 `1.2.0` Windows 文件版本、产品名称和说明
- 更新当前配置页欢迎语，引导用户点击左侧二维码支持作者

- 新增 `reset_onboarding.bat`，用于开发测试时重新开启新手引导弹窗
- 修复新增配置生成精简模板导致 Codex 身份字段丢失的问题：现在先复制当前配置文件，再只修改连接参数，避免保存并使用后产生新的会话身份
- README 增加首次启动、当前配置、切换配置、官方登录、新手引导、关于软件和赞赏窗口截图；原始图片统一保存到 `docs/images/`
