# 变更摘要

## 1.4.0

- 新增供应商模型列表获取与下拉选择，并保留 Model 手动输入
- 修复官方登录模式切换时删除配置文件导致聊天记录和会话状态丢失的问题
- 更新 README 当前配置页截图，展示模型下拉选择
- 精简官方登录页面和确认提示，避免说明文字超出面板边界
- 修正官方登录页面说明，明确不会删除 `auth.json`、`config.toml` 或会话数据
- 官方登录与 API 配置切换改为非破坏性字段合并，不再删除 `auth.json` 或 `config.toml`
- 切换过程中保留 ChatGPT 登录令牌、会话标识、聊天记录目录、历史记录及未知配置字段
- 增加 API-A → 官方登录 → API-K 的会话保留和双文件失败回滚测试
- 当前配置页新增 OpenAI 兼容 `/models` 模型列表获取，并同时支持下拉选择和手动输入
- 模型列表请求只在用户主动点击后发起，并设置超时、响应大小限制和禁止重定向
- 选择模型后立即更新当前 `config.toml`，无需额外确认或保存按钮
- 当前配置匹配已保存配置时同步更新其 Model，任一写入失败会恢复两边原内容
- 获取或保存失败时保留原模型，新增和编辑配置仍支持手动填写 Model
- Model 下拉按钮使用内缩的小型线条 chevron；输入框与弹窗外框统一为四边 `2px`，列表隐藏滚动条并保留滚轮、方向键和键入定位
- 配置列表双击切换扩展到整行，名称、Base URL 和行内空白均可触发
- 增加模型接口解析、鉴权请求、配置同步和事务回滚测试

## 1.3.0

- 左侧导航新增“一键重启”，确认后关闭并重新启动 Codex
- Codex 未运行时，一键重启会自动切换为启动 Codex
- 一键重启优先正常关闭 Codex，避免“跟随系统”等显示设置因强制结束而回退
- 修复无顶层窗口时立即强制结束的问题，先等待正常退出再执行超时兜底
- 支持识别 Microsoft Store 和普通桌面安装的 Codex，只处理 Codex 桌面应用
- 优化长 API Key 的横向浏览、选择和键盘定位体验
- 按新版视觉规范统一所有 API Key 显示与隐藏图标
- 修复长 Key 越界拖选时原生与自定义逻辑冲突导致的边界字符闪烁
- README 新增一键重启截图和使用说明，交接文档同步记录重启流程约束

## 1.2.0

- 将产品定位统一为 Codex 配置管理与切换工具
- 新增固定窗口、左侧导航和当前配置只读页面
- 新增配置库搜索、排序、切换、完整编辑、重命名、删除和批量删除
- 新增全选、Ctrl+A、鼠标左键拖选和双击空白区域切换
- 配置永久保留，不设数量上限，不自动删除或更新时间
- 保存相同核心配置时复用已有配置，避免重复目录
- 新增官方登录页面和一次性居中新手引导
- 增加 Windows 单实例限制和正常退出后的互斥量释放
- 统一软件图标、眼睛图标、扁平按钮、列表边框和自绘滚动条
- 瞬时消息改为无背景纯文字，眼睛按钮移除悬停提示
- 最小化和关闭图标改为以按钮几何中心绘制，修正字体基线导致的视觉偏移
- README、HANDOFF、测试和 PyInstaller 打包资源同步更新
- 统一当前配置页和已保存配置页的标题、控件高度与底部瞬时提示区域
- 启动新手引导改为“是/否/不再弹出”，明确禁用前每次启动继续询问
- 标题栏按钮改用独立清晰图标，任务栏与弹窗分别使用对应图标资源
- Windows 使用原生任务栏缩放动画，并通过非客户区处理保留单一自绘标题栏
- 侧栏和弹窗分别原尺寸加载 105/210 像素赞赏码
- 多选右键仅提供批量删除；删除匹配项后保留当前配置文件并显示为未保存配置
- 配置与设置改用同目录原子替换，双文件保存失败时自动回滚
- 配置签名和列表搜索增加自动失效的 512 项 LRU 缓存
- 增加写入故障注入、事务回滚和缓存失效测试
- EXE 嵌入 `1.2.0` Windows 文件版本、产品名称和说明
- 更新当前配置页欢迎语，引导用户点击左侧二维码支持作者

- 新增 `reset_onboarding.bat`，用于开发测试时重新开启新手引导弹窗
- 修复新增配置生成精简模板导致 Codex 身份字段丢失的问题：现在先复制当前配置文件，再只修改连接参数，避免保存并使用后产生新的会话身份
- README 增加首次启动、当前配置、切换配置、官方登录、新手引导、关于软件和赞赏窗口截图；原始图片统一保存到 `docs/images/`
